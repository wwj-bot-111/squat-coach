# 深蹲姿态识别辅助系统 🏋️

结合人工智能与体育知识，开发的一套**深蹲姿态识别辅助系统**。基于 [MediaPipe](https://ai.google.dev/edge/mediapipe) 人体关键点检测，用手机/电脑摄像头实时识别深蹲动作，自动计数、评级并给出动作纠正。

## ✨ 功能

- **实时人体关键点检测**：识别 33 个关节点并绘制骨架
- **自动计数**：状态机（站立 ⇄ 下蹲）+ 连续帧防抖，稳定不漏计
- **三档评级**：Excellent（优秀）/ Great（合格）/ Fail（不合格）
- **慢下快上节奏分析**：专业力量训练讲究"蹲下慢、起身快"，系统会计算下蹲/起身用时和节奏比
- **前倾角分档**：无 / 轻微前倾 / 过度前倾
- **动作纠错**：深度不足、过度前倾、膝盖前移
- **一键导出报告**：生成 TXT 运动记录（含汇总 + 每次动作明细）

## 🏆 评分标准

```
Excellent = 深度达标(大腿平行或更低) 且 慢下快上(节奏比≥1.5) 且 无过度前倾(≤40°)
Great     = 深度 ≤ 0.50
Fail      = 深度 > 0.50
```

## 🚀 使用方法

1. 用手机/电脑浏览器打开本网页
2. 允许摄像头权限
3. 全身入镜（建议侧身站立），点「开始运动」
4. 做深蹲，实时查看计数和评级
5. 做完点「结束运动」→「导出报告」
